# わたしのリズム v0.7.2

## 今回の変更
- 最新の生理記録に「終了日」が入力されるまでは、次回生理予定日・排卵予測・妊娠しやすさ指数を表示しません。
- 生理終了日を入力して「生理期間を保存」を押すと、次回生理予定日を自動表示します。
- 次回予定日は生理終了日からではなく、直近の生理**開始日**と周期から計算します。
- 開始日だけの記録も保存可能です。後日同じ開始日で終了日を追記できます。
- 既存の記録は同じブラウザの localStorage に保持されます。更新前にバックアップを取ってください。

## 公開方法
ZIPを解凍して、中身のファイルをGitHubリポジトリのルートへアップロードし、既存ファイルを置き換えてください。

## 注意
周期・排卵・妊娠しやすさ指数は推定であり、実際の妊娠確率ではありません。避妊判断には使わないでください。
