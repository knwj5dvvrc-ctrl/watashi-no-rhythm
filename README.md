# わたしのリズム v0.7

ラベンダーUI・本人専用・ローカル保存の生理管理Webアプリです。

## v0.7の追加
- 生理周期から排卵予測日を計算（次回生理開始予測日の約14日前）
- 排卵予測日前5日〜翌日の期間をカレンダーに表示
- 基礎体温を日付ごとに記録、直近30日のグラフを表示
- 妊娠しやすさ指数を0〜100%の相対指標として表示（**実際の妊娠確率ではありません**）

## 利用上の注意
指数は排卵予測日からの日数に基づく表示用スコアです。臨床的に検証された確率ではなく、0%でも妊娠しないという意味ではありません。生理周期から排卵日を正確に特定できません。避妊、妊娠判定、医療判断に使用しないでください。

## GitHub Pages
ZIPを展開し、ファイル一式をリポジトリのルートにアップロード。Settings → Pages → Deploy from a branch → main / root で公開。すでにインストール済みの場合は再読み込みで更新してください。

## データ保存
localStorage の `futari-rhythm-v1` を継続使用するため、v0.6の記録を引き継ぎます。同じブラウザ・同じURLで使用してください。バックアップは設定からJSONで書き出せます。
