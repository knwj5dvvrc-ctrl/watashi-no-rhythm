# わたしのリズム v0.6 — ホーム画面アイコン対応

v0.5の機能・ローカル保存方式を維持し、選んだ花のアイコンを追加しました。

## GitHubへアップロード

ZIPを解凍し、**中のファイルをすべて**リポジトリの最上位にアップロードしてください。ZIPのままアップロードしないでください。既存の `index.html` は上書きしてください。GitHub Pages の Settings → Pages で `Deploy from a branch`、`main`、`/(root)` を選びます。

公開後、iPhoneのSafariでGitHub PagesのURLを開き、共有ボタン → ホーム画面に追加。すでに追加していた場合は古いアイコンが残ることがあるため、ホーム画面のショートカットを削除して再追加してください（Webアプリ内のデータを消さないよう注意）。

## ファイル

- `index.html`: アプリ本体
- `apple-touch-icon.png`: iPhone用アイコン
- `icon-192.png`, `icon-512.png`: PWA用アイコン
- `icon-1024.png`: 元の高画質アイコン
- `favicon-32.png`: ブラウザ用アイコン
- `manifest.webmanifest`: PWA設定
- `sw.js`: 静的ファイルのオフラインキャッシュ

## プライバシーと注意

生理・体調記録は従来通りブラウザのlocalStorageに保存され、GitHubにアップロードされません。キャッシュにはアプリの静的ファイルのみ保存します。ブラウザデータを消すと記録が失われるため、設定からバックアップしてください。GitHub PagesのURL（ドメイン・パス）を変えると記録が引き継がれない場合があります。生理予測は医療目的・避妊目的には使えません。
