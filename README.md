# わたしのリズム v0.7.4

- 10月20日開始・10月25日終了の記録がある場合、28日周期の次回予定日は11月17日。予定日を過ぎても12月15日に自動繰り上げしません。
- 11月の生理開始だけ記録した段階では次回予測を出さず、終了日を登録すると新しい周期の予測に切り替わります。
- 排卵予測も現在待っている生理予定日を基準に表示します（過去の推定日は過去として表示）。
- ホーム上部に v0.7.4 を表示し、古い画面のキャッシュを判別しやすくしました。

## GitHub Pages への更新

ZIPを展開し、ファイルをすべてリポジトリ直下にアップロードして既存ファイルを置き換えます。GitHub Pagesが更新されてからSafariで再読み込みしてください。表示に v0.7.4 が出ない場合は古いキャッシュの可能性があります。ブラウザのサイトデータを消すと生理記録も失われるので、先に設定からJSONバックアップを保存してください。

予測は医療的診断ではなく、妊娠確率や避妊の判断に使えません。
