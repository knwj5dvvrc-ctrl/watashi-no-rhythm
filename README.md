# わたしのリズム v0.5

大人っぽいラベンダーを基調にした、本人専用の生理・体調管理Webアプリです。

## 使い方

`index.html` をブラウザで開いてください。ホーム、カレンダー、体調記録、設定の4タブがあります。生理の開始日と終了日、気分、複数の症状、メモを記録できます。

## データと互換性

v0.4と同じ `localStorage` キー `futari-rhythm-v1` を使います。同じブラウザ・同じオリジンで開いた場合は以前の記録を引き継げます。URLや保存場所が変わるとブラウザの保存領域が異なるため、旧版でJSONバックアップを書き出し、新版の設定から復元してください。

ブラウザのローカル保存は暗号化されません。端末やブラウザのデータを消すと記録も消えます。定期的にJSONバックアップを安全な場所へ保存してください。共有・ログイン・外部送信・Firebaseはありません。

## 予測について

直近の有効な周期（18〜45日）の最大6件の平均を使い、記録が少ない場合は28日を仮定します。生理期間は記録の平均、なければ5日を仮定します。医療判断や避妊には使用できません。
